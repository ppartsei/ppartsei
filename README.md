## Мои проекты

 **Предсказание рейтинга объявления**  -  ML‑модель для выявления перспективных объявлений об аренде жилья на этапе публикации (проблема «холодного старта»). Разработан производственный пайплайн пакетного инференса на Apache Airflow. Модель выделяет 16% наиболее конверсионных объявлений с высоким рейтингом прямо в момент создания. (https://github.com/ppartsei/Property_Market_Prediction.git)
**Выявление заказов с высоким риском задержки**  -  ML‑модель прогнозирования риска задержки доставки. Включает EDA, географическую и поведенческую кластеризацию. Качество на тестовой выборке: ROC‑AUC 0.7709 (выше целевого 0.75). Подтверждена ценность кластерных признаков. (https://github.com/ppartsei/Delivery_delay_prediction.git)
**A/B‑тестирование алгоритма рекомендаций**  -  Спроектирован и проанализирован A/B‑эксперимент для нового алгоритма ранжирования коротких видео. Статистически доказано отсутствие улучшений вовлечённости — это позволило отклонить неэффективную версию и перераспределить фокус команды.
